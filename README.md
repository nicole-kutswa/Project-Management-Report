# Project Management BI Reporting System

An interactive **Business Intelligence reporting system built in Power BI** for monitoring a portfolio of projects across performance, cost, benefits, timelines, and completion.

The system transforms project data into a structured reporting environment that supports both **portfolio-level monitoring and project-level investigation**.

## Reporting System

The report is organised into three interconnected views:

### 1. Project Summary

Provides a portfolio-level overview through:

* Total projects, cost, benefits, and benefit-cost ratio
* Project status and phase
* Regional and departmental distribution
* Project complexity
* Project trends over time

### 2. Project Timeline

Provides a scheduling and progress view using:

* Project trends over time
* Gantt-style project timelines
* Project phases
* Start and end dates
* Completion percentage

### 3. Project Details

Provides granular project-level information, including:

* Project type and region
* Project manager
* Complexity
* Cost and expected benefit
* Completion percentage
* Current status

Interactive filters allow users to explore the portfolio by **year, project, project type, project manager, and region**.

##  Business Questions

The reporting system helps stakeholders investigate:

* What is the current state of the project portfolio?
* How are projects progressing against their timelines?
* Where are projects distributed across regions, departments, and phases?
* How do project costs compare with expected benefits?
* Which individual projects require closer investigation?

##  Technology

* **Power BI** — reporting, visualisation, and dashboard development
* **Power Query** — data preparation and transformation
* **DAX** — calculated measures and KPIs
* **Data Modelling** — structuring data for interactive analysis

##  BI Workflow

```text
Project Data
     ↓
Data Preparation
     ↓
Data Modelling
     ↓
DAX Measures
     ↓
Interactive Reporting
     ↓
Project Insights
```

The system follows an **overview → timeline → detail** reporting structure, allowing users to move from portfolio-level performance to individual project records.
